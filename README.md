# Wizard of Things

## Using LLMs for Rapid Prototyping of IoT Projects

*By Amir Reza Asadi and Lily Edinam Botsyoe*  
*School of IT, University of Cincinnati*  
*Presented at IT Expo 2024*

## Overview

Wizard of Things is a novel approach for rapid prototyping of Internet of Things (IoT) and smart home systems using Large Language Models (LLMs). This iOS application allows designers and researchers to simulate IoT environments without physical hardware.

**GitHub Repository:** [https://github.com/AmirrezaAsadi/wizardofThings](https://github.com/AmirrezaAsadi/wizardofThings)

## Key Features

- iOS application connected to OpenAI's GPT-4 API
- Rapid prototyping of IoT systems without hardware dependencies
- Simulation of sensors, actuators, and environmental conditions
- Generation of synthetic sensor data using LLMs
- Decision-making for IoT systems
- "Diary of Things" for user studies
